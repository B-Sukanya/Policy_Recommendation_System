# Policy Recommendation System

## Overview

This project is an AI-powered insurance recommendation system that analyzes
customer information and requirements to suggest personalized insurance
products.

The system is designed to help identify suitable insurance options based on
individual customer needs, making the recommendation process more
personalized and data-driven.

## Key Features

- Analyzes customer information and requirements
- Provides personalized insurance recommendations
- Uses AI-driven recommendation logic
- Simple Python-based implementation
- Easy to extend with additional insurance products and customer attributes

## Technologies Used

- Python
- Pandas
- Streamlit
